# koen.klinke.rs

## Tools that I made that work for me.

- [regect](https://github.com/kloki/regect) — regex 101 in the terminal
- [absorb](https://github.com/kloki/absorb) — speed-read files in the terminal
- [stpl](https://github.com/kloki/stpl) — CLI notes for humans and agents
- [ocpop](https://github.com/kloki/ocpop) — a waybar widget for opencode
- [claudeship](https://github.com/kloki/claudeship) — a custom statusline for Claude Code
- [mavsnark](https://github.com/kloki/mavsnark) — a terminal UI for inspecting MAVLink traffic in real time
- [tldr](https://github.com/kloki/tldr) — a CI tool that enforces a maximum file length in a project

## Games that I made that you can play.

- [Finger and Toes](https://koen.klinke.rs/fingers-and-toes/) — a fun game to lose some money on
- [Hyper Tic Tac Toe](https://koen.klinke.rs/hyper-tic-tac-toe/) — tic-tac-toe where every square is its own tic-tac-toe board
- [BigBrainWordle](https://github.com/kloki/bigbrainwordle) — cheat at Wordle
